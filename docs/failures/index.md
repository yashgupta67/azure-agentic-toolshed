# Failures, indexed by the literal error text

If you pasted an exact error message into a search engine and landed here, you're in the right section. Microsoft's own docs generally don't publish "here's what breaks" — this section exists specifically to fill that gap, one literal error string at a time.

Each page here is titled with the exact text a developer would paste into a search box, not a paraphrase. Pages are added only once an error has actually been hit and captured — nothing here is speculative.

## Index

Nothing has been captured yet. As artifacts in this repo get deployed and tested, real error strings — from Bicep validation failures, Easy Auth misconfiguration, connector authentication issues, or an agent host rejecting a transport it doesn't support — land here with the literal text, the cause, and the fix.

If you hit an error while building any artifact in this repo, that error belongs here. See [`../logic-apps-mcp/conventions.md`](../logic-apps-mcp/conventions.md) for how the rest of this site is structured.
